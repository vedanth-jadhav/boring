# Boring Notch Octave for Windows 1.0.0

This x64 Windows edition brings the original island layout to screens without a notch, with selectable feature onboarding, smooth pointer-driven open and close motion, music and lyrics, focus and caffeine timers, a local file shelf, calendar reminders, Codex usage, and Windows system tools.

Download and extract `Boring-Notch-Octave-Windows-x64.zip`, then run `Setup.cmd`. The setup installs for the current Windows account and does not require administrator rights. The accompanying SHA-256 file verifies the archive.

Windows 10 22H2 or Windows 11, x64. This build is unsigned; Windows may show its download warning. The included [Windows guide](https://github.com/vedanth-jadhav/boring/blob/codex/windows-port/windows/README.md) covers Octave extension setup and feature details.

The project was built and tested in Linux CI with Windows cross-compilation. Physical Windows device integrations and the installer have not been runtime-tested on a Windows machine yet. See [QA.md](https://github.com/vedanth-jadhav/boring/blob/codex/windows-port/windows/QA.md).
